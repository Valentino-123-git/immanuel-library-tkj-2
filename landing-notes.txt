CATATAN BAGIAN YANG BELUM SAYA MENGERTI
Proyek: immanuel_library

1. Validation
- Saya belum terlalu paham kenapa validasi ditaruh di folder validations
  dan dipisah dari file actions. Kenapa tidak langsung dicek di dalam
  satu file saja?
- Saya juga masih bingung bagaimana pesan error validasi bisa balik
  ke form dan tampil di halaman.

2. Authentication
- Saya belum yakin bagaimana session bisa "mengingat" kalau user
  sudah login, padahal tiap pindah halaman itu request baru.
- Saya ingin tahu kenapa password harus di-hash dan tidak disimpan
  apa adanya di database.

3. Authorization
- Saya masih bingung bedanya authentication dan authorization,
  karena sama-sama soal login.
- Saya belum paham cara kerja middleware: kapan dia dijalankan,
  dan bagaimana dia bisa menolak user masuk ke halaman tertentu.

4. Filter and Pagination
- Saya belum paham cara menghitung LIMIT dan OFFSET dari nomor halaman.
- Saya juga bingung bagaimana filter (misalnya kategori buku) bisa
  tetap jalan waktu pindah ke halaman berikutnya.

Kendala lain:
- Waktu push ke GitHub saya sempat bingung soal remote origin dan
  kenapa jumlah file yang berubah terlihat sedikit.
